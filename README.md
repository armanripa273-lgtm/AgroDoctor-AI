# AgroDoctor AI

Учебное мобильное приложение для наблюдения за растениями. Разработчик — Беляев Диас. Стек: React Native, TypeScript, Expo SDK 58. Приложение запускается в Expo Go, совместимом с SDK 58.

## Визуальный стиль

Интерфейс оформлен как яркий полевой дневник: существующая ботаническая иллюстрация служит общей рамкой экранов, а карточки используют оттенки листьев, томатов, огурцов, солнца и воды. Основные цвета, интервалы и радиусы собраны в `src/theme.ts`. Главный экран выделяет фотопроверку тёплым томатным цветом; коллекция растений и каталог используют отдельные цветовые метки; формы и чат сохраняют контрастные бумажные поверхности для читаемости. Нижняя навигация и важные действия имеют увеличенные зоны нажатия.

## Возможности

- Регистрация по email и паролю через Firebase Authentication с письмом для подтверждения адреса.
- Главная страница, сервисы, каталог болезней, растения и профиль: навигация Stack + Bottom Tabs.
- Карточки растений и история наблюдений с заметками и состоянием.
- Фото из галереи или камеры, сравнение снимков «до/после».
- Геолокация наблюдения по разрешению пользователя.
- Локальное хранение растений, наблюдений и профиля через AsyncStorage.
- AI-анализ фотографии через Gemini: видимые признаки, возможные причины и рекомендации. Результат можно перенести в новое наблюдение.
- AI-чат Gemini получает карточки растений, недавние наблюдения, напоминания и каталог болезней; по запросу может помочь перейти к разделу, создать/изменить/удалить карточку, добавить наблюдение или предложить напоминание. Любое изменение требует подтверждения пользователя.
- Проактивная AI-сводка автоматически перепроверяет новые сохранённые наблюдения и до двух последних фотографий, показывает состояние каждого растения на главной и даёт рекомендации. Результат кэшируется на 12 часов, а новая запись запускает повторную проверку.
- Локальные напоминания о поливе и уходе на устройстве; список и удаление доступны в разделе «Напоминания».
- Рекомендации и каталог болезней. AI-ответ — подсказка, а не окончательный агрономический диагноз.

В AI-чате можно приложить фото из галереи или сделать снимок. Изображение отправляется Gemini только вместе с отправленным сообщением. Чат показывает, какие данные приложения передаются для ответа; email, пароль и GPS координаты в AI-запрос не включаются.

## Запуск

1. Установите Node.js LTS и Expo Go, совместимый с SDK 58.
2. Откройте терминал в корне проекта и выполните `npm install`.
3. Для AI-анализа создайте `.env.local` рядом с `package.json` и добавьте строку `EXPO_PUBLIC_GEMINI_API_KEY=ваш_ключ_из_Google_AI_Studio` (образец — `.env.example`).
4. Выполните `npm start` и отсканируйте QR-код телефоном. Компьютер и телефон должны быть в одной сети.

На главной странице нажмите «Спросить AgroDoctor AI» либо откройте «Сервисы» → «AI-чат». Можно задать обычный вопрос, попросить оценить фото, добавить растение/наблюдение или установить напоминание. Gemini возвращает предложенное действие, а приложение выполняет его только после подтверждения. AI-анализ изображения также доступен через кнопку «Проверить растение».

Локальные уведомления настраиваются в разделе «Напоминания» через AI-чат: например, «Напомни полить фикус завтра в 9:00» или «Напоминай осматривать томат каждый день в 18:30». Разреши уведомления в системном запросе Android. Уведомления сохраняются на устройстве и не требуют сервера; удалённая рассылка на другие устройства потребует backend.

Автоматическая AI-сводка запускается при сохранении наблюдения и при открытии главной. Если приложение закрыто, оно не анализирует растения в фоне: постоянный мониторинг и отправка уведомления без запуска приложения потребуют отдельного сервера/фоновой инфраструктуры.

Ключ из `.env.local` не попадает в GitHub, но `EXPO_PUBLIC_`-переменная включается в JS-бандл Expo Go и доступна на устройстве. Такой способ подходит лишь для учебной демонстрации. Для публичного приложения с собственным общим ключом нужен сервер-посредник, ограничения расхода и контроль запросов. Если ключ уже где-либо опубликован, выпустите новый в Google AI Studio.

Для проверки типов: `npm run typecheck`.

## Авторизация и данные

Конфигурация Firebase Web App проекта `agrodoctor-ai` находится в `src/services/firebase.ts`. В Firebase Console должен быть включён способ входа **Email/Password**. При регистрации Firebase создаёт пользователя и отправляет письмо подтверждения; проверьте также папки «Спам» и «Промоакции». Пароль от Gmail приложению не нужен. Если заменить конфигурацию на заглушки, интерфейс переключается на учебный код без настоящей отправки письма.

Конфигурация Firebase Web App видна в клиентском приложении и не является серверным секретом. Для публичного использования нужно настроить правила доступа Firebase, ограничения ключа и меры защиты от злоупотреблений. Пользовательские фото и наблюдения сейчас остаются на устройстве; облачной синхронизации нет.

## Ограничения

Gemini действительно обрабатывает текст и отправленные фото, но визуальная оценка может ошибаться и не заменяет осмотр агронома или лабораторный анализ. AI чат не меняет настройки, учётную запись или данные без подтверждения, не выполняет произвольный код и не может обещать точность биологического диагноза. Ключ API сейчас вызывается с клиентского приложения; для публичного использования перенеси Gemini запросы на сервер, чтобы защитить ключ и ограничивать злоупотребления. Облачной синхронизации растений и наблюдений пока нет.
